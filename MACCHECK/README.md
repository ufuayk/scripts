# MACCHECK

Checks the macOS version and prints the version number along with its version name (codename). Works from Mac OS X 10.0 up through the latest macOS releases.

---

| Output          | Meaning                                  |
| --------------- | ---------------------------------------- |
| macOS Version   | The raw version number (e.g. 14.5)       |
| Version Name    | The codename (e.g. Sonoma)               |

---

**Usage:**

```bash
./MACCHECK.rb
```
